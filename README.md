# СБОРКА

Веб-платформа заказа сборки мебели в Якутске. Клиент считает стоимость и оставляет заявку, мастера откликаются, клиент выбирает по цене и рейтингу. Комиссия платформы 30%.

## С чего начать (для Claude на сервере)

1. Прочитай `CLAUDE.md` — контекст, правила, стек, тон общения с владельцем.
2. Прочитай `design-system.md` — токены и компоненты. Не изобретай новый дизайн.
3. Открой `reference/mockup.html` — кликабельный макет всех экранов, эталон вида и логики.
4. `docs/concept.md` — полная продуктовая концепция. `docs/roadmap.md` — этапы.
5. Уточни у владельца параметры сервера (ОС, что установлено, домен) — потом настраивай окружение.

## Структура

```
CLAUDE.md          — контекст и правила проекта
design-system.md   — дизайн-токены и компоненты
public/            — фронтенд (index.html = стартовая точка из макета)
src/               — бэкенд (создать под выбранный стек)
reference/         — mockup.html: эталонный кликабельный макет
docs/              — concept.md, roadmap.md
```

## Первый рабочий этап

Лендинг с калькулятором + форма заявки (клиент считает → оставляет заявку с телефоном → падает владельцу). Позволяет запуститься за 1–2 недели и проверить поток, пока личные кабинеты и отклики достраиваются. Дальше — по `docs/roadmap.md`.
